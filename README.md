# MiBox4-LibreELEC
This repository contains device tree files and patches for the Xiaomi Mi Box 4 (MDZ-21-AA), intended for use with LibreELEC.

The original DTB/DTS files were extracted from the stock firmware with the assistance of Codex.

The adapted device tree adds support for the internal eMMC storage, Bluetooth, and Wi-Fi. Bluetooth and Wi-Fi are provided by the RTL8723DS chipset using drivers from the mainline Linux kernel.
